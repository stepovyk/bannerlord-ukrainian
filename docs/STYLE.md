# Посібник перекладача

Мета — повна, природна, літературна українська локалізація рівня найкращих офіційних. Перекладаємо з англійського оригіналу гри. Інші переклади можна дивитися лише для розуміння контексту; ніколи не калькуємо російські слова й звороти.

Як улаштовано репозиторій і як надсилати правки — у [README](../README.md#як-долучитися). Затверджені рішення щодо термінів — у [GLOSSARY.md](GLOSSARY.md).

## 1. Стиль

- Жива літературна мова, без русизмів і суржику. Середньовічне фентезі: лицарі, лорди, королівства, степовики, пустельні султанати. Лексика — колоритна, але зрозуміла; не архаїзуй надміру.
- Персонажі говорять по-різному: лорд — гордовито, селянин — просто, розбійник — грубо. Зберігай тон, гумор, іронію оригіналу. Не скорочуй зміст і не додавай свого.
- Гравця називаємо на «ви» (з малої літери; з великої — лише на початку речення). Груба мова розбійників, близьких родичів, подружжя — можна «ти», якщо так природніше.
- Інтерфейс (кнопки, підказки, назви вкладок) — стисло: «Найняти», «Залишити», «Покинути загін». Заголовки — з великої лише перше слово (англ. «Main Menu» → «Головне меню»).
- Лапки — «ялинки» `«…»`. Тире — `—` з пробілами. Апостроф — `’` (U+2019): «м’ясо», «сім’я», «здоров’я». Три крапки — `...`.
- Числа й одиниці лишай як є; «%» без пробілу, як в оригіналі.
- Русизми-пастки (вживай праве): приймати участь → брати участь; на протязі → протягом; слідуючий → наступний; являється → є; получати → отримувати; міроприємство → захід; співпадати → збігатися; любий (будь-який) → будь-який; самий кращий → найкращий; вірно (правильно) → правильно; рахувати (вважати) → вважати; відмінити → скасувати; виключення → виняток; на рахунок → щодо; згідно чого → згідно з чим; пройти мимо → пройти повз; заказ → замовлення; урон → шкода; оружжя → зброя; доля (частка) → частка; бувший → колишній; уміти/знати не плутати; «вибачаюсь» → «вибачте/перепрошую»; «добро пожалувати» → «ласкаво просимо»; «хватить» → «досить»; «прийшлось» → «довелося»; «приймати міри» → «вживати заходів».

## 2. Розмітку зберігай БЕЗ ЗМІН

Усе у фігурних та квадратних дужках — код гри. Не перекладай імен змінних і не змінюй їх.

- Змінні: `{VALUE}`, `{HERO.NAME}`, `{QUEST_GIVER.LINK}`, `{GOLD_ICON}`, `{newline}` — кожна змінна з оригіналу має бути в перекладі (стільки ж разів; порядок можна міняти під граматику).
- Умови: `{?УМОВА}текст якщо так{?}текст якщо ні{\?}`, ланцюжки `{?A}…{:?B}…{:}…{\?}`. Структуру зберігай, вміст гілок перекладай. Не плутай `{?}` (роздільник) і `{\?}` (кінець).
- Поля: `{@Plural}…{\@}`, вибір `{#IS_LEFT}…{#}…{\#}` — зберігай, вміст перекладай.
- Теги анімації в діалогах `[ib:confident][if:convo_bored][rf:…][rb:…]` — лиши всі, на тих самих місцях у фразі (зазвичай на початку чи в кінці речення).
- HTML: `<a …>`, `<b>`, `</b>`, `<img …>`, `<br>` — без змін.
- Функції `{PLURAL(ITEM)}`, `{ABS(AMOUNT)}` — без змін.
- Англійські службові токени `{.a}` (артикль a/an), `{.A}`, `{.s}` (множина), `{.o}` (присвійне 's) — в українському тексті ВИДАЛЯЙ: вони англійські. Замість них — українська граматика (див. розділи 4–5). `{.%}`(нижній регістр між парою маркерів), `{.^}` (велика наступна літера), `{._}` (мала наступна літера) — можна лишати, якщо доречно.

## 3. Рід персонажів

- Для персонажа-змінної, що має атрибут статі, — умова: `{?X.GENDER}жіноча форма{?}чоловіча форма{\?}` (жіноча — ПЕРША). Приклади: `{?QUEST_GIVER.GENDER}вдячна{?}вдячний{\?}`, `{?PLAYER.GENDER}пані{?}пане{\?}`.
- Атрибут `.GENDER` мають змінні-персонажі: PLAYER, SPEAKER, LISTENER, CONVERSATION_NPC, QUEST_GIVER, ISSUE_GIVER, ISSUE_OWNER, HERO, LORD, RULER, NOTABLE, TARGET_HERO, COMPANION, CHILD, PRISONER, OWNER тощо — орієнтуйся на те, що в цьому ж рядку оригінал уже використовує `.NAME/.LINK/.GENDER` для цієї змінної. Не вигадуй `.GENDER` для змінних, що ніде не трапляються як персонаж.
- Гравець — «ви», тому дієслова минулого часу вже нейтральні: «Ви захопили», «Ви поранені».
- Перша особа NPC у діалогах («я зробив/зробила»): найкраще — нейтральна побудова («Мені вдалося…», «Я зроблю…», «Я це бачу»). Якщо без роду не обійтися — `{?SPEAKER.GENDER}зробила{?}зробив{\?}` у репліках NPC (вони зазвичай мають теги `[ib:…][if:…]`). У репліках гравця (варіанти відповіді, без тегів анімації) рід мовця — `{?PLAYER.GENDER}…{?}…{\?}`.
- Звертання NPC до гравця: «my lord / my lady» → `{?PLAYER.GENDER}пані{?}пане{\?}` (кличний відмінок, «моя пані/мій пане» — за контекстом).

## 4. Відмінювання назв (власний обробник граматики мода)

Мод містить український граматичний процесор. Він відмінює назви, вставлені змінними, — якщо назва має маркери, а в шаблоні після змінної стоїть токен відмінка.

### 4.1. Маркери в НАЗВАХ (рядки-назви: поселення, королівства, клани, культури, імена, війська, предмети, будівлі тощо)

Кожна назва, яку гра може підставити в речення (поселення, королівство, клан, культура, ім’я, військо, предмет, будівля тощо), ОБОВ’ЯЗКОВО має маркери за українським родом слова.

- Маркер роду на ПОЧАТКУ назви: `{.MA}` чоловічий істота, `{.MI}` чоловічий неістота, `{.FA}`/`{.FI}` жіночий, `{.NA}`/`{.NI}` середній, `{.PA}`/`{.PI}` — лише множина (наручі, ворота, сани; народ/клан у множині: «Кергіти» → `{.PA}`).
  - Істота (A): люди, тварини, війська, імена, прізвиська. Неістота (I): поселення, держави, клани (як організації), предмети, будівлі, поняття.
- Однослівна назва: лише маркер роду: `{.MI}Тисмил`, `{.FI}Вландія`, `{.MA}Дертерт`, `{.FA}Ліена`.
- Багатослівна: після кожного слова, що відмінюється, — `{.aj}` (прикметник, дієприкметник, порядковий числівник) або `{.nn}` (іменник). Слова без позначки НЕ змінюються (родові доповнення, прийменникові групи, незмінні частки):
  - `{.FI}Північна{.aj} імперія{.nn}`
  - `{.MA}Імперський{.aj} рекрут{.nn}`
  - `{.MI}Щит{.nn} хана`
  - `{.MI}Шолом{.nn} з наносником поверх стьобаного каптура`
  - `{.NI}Хузаїтське{.aj} ханство{.nn}`
  - `{.PA}Лісові{.aj} розбійники{.nn}`
  - `{.MI}Асерайський{.aj} султанат{.nn}`
- Прикладка з іншим родом (прізвисько): маркер роду можна ставити перед словом посередині, він діє на наступні слова: `{.MA}Ролан{.nn} {.FA}Скеля{.nn}` («Ролана Скелю»).
- Незмінні власні назви (наприклад, родові частки «фен», «дей», арабізовані «Бану …», якщо відмінювати незграбно) — без маркерів.
- Назва з полем множини (`{@Plural}…{\@}`, товари): основна назва з маркерами, а в полі `Plural` — одиничне «тарне» словосполучення з маркерами, яке узгоджується з числом через `{.c}` (див. 5.2): `{.NI}Зерно{@Plural}{.MI}мішок{.nn} зерна{\@}`, `{.NI}Вино{@Plural}{.FI}бочка{.nn} вина{\@}`.

### 4.2. Токени відмінків у ШАБЛОНАХ (речення, куди підставляються назви)

Після змінної з назвою пиши токен потрібного відмінка — назва відмінюється автоматично:

| Токен | Відмінок | Приклад |
|---|---|---|
| (нічого) або `{.n}` | називний | `{SETTLEMENT} у вогні` |
| `{.g}` | родовий | `до {SETTLEMENT}{.g}`, `армія {HERO.LINK}{.g}` |
| `{.d}` | давальний | `допомогти {QUEST_GIVER.LINK}{.d}` |
| `{.a}` | знахідний | `захопити {SETTLEMENT}{.a}` |
| `{.i}` | орудний | `з {KINGDOM}{.i}`, `під {SETTLEMENT}{.i}` |
| `{.l}` | місцевий | `у {SETTLEMENT}{.l}`, `на {X}{.l}` |
| `{.v}` | кличний | `Вітаю, {PLAYER.NAME}{.v}!` (лише для звертань) |
| `{.p}` | називний множини | `{TROOP}{.p}` → «Імперські рекрути» |
| `{.gp}` `{.dp}` `{.ap}` `{.ip}` `{.lp}` | множина: родовий, давальний, знахідний, орудний, місцевий | `кілька {TROOP}{.gp}` |

- Працює для змінних, у які підставляється назва з маркерами, і для `.NAME`/`.LINK` персонажів. Відмінок обирай за українською граматикою: «у Вландії» — `{.l}`, «до Вландії» — `{.g}`, «з Вландією» — `{.i}`, «війна з {X}» → `з {X}{.i}`.
- Українська мова вимагає відмінка — не уникай його штучно. Але якщо змінна — не назва (число, ціла фраза, опис), токен не став.
- Ім’я гравця (`{PLAYER.NAME}`) гравець вводить сам, і рід його невідомий процесору: став до нього відмінкові токени лише коли без цього не обійтися; краще конструкції з називним.

### 4.3. Узгодження з назвою-змінною (рід/число невідомі наперед)

Для змінних-назв (НЕ персонажів — для персонажів є `.GENDER`) є функції, що повертають закінчення залежно від роду назви. Пиши основу слова + функцію:

| Функція | ч. | ж. | с. | мн. | Приклад |
|---|---|---|---|---|---|
| `{adj(X)}` твердий прикметник/дієприкметник | ий | а | е | і | `{SETTLEMENT} захоплен{adj(SETTLEMENT)}` |
| `{adjs(X)}` м’який прикметник | ій | я | є | і | `останн{adjs(X)}` |
| `{past(X)}` дієслово мин. часу на голосну | в | ла | ло | ли | `{SETTLEMENT} впа{past(SETTLEMENT)}` |
| `{pron(X)}` він/вона/воно/вони | | | | | |
| `{prong(X)}` його/її/його/їх (родовий, знахідний без прийменника) | | | | | |
| `{prond(X)}` йому/їй/йому/їм | | | | | |
| `{pronp(X)}` нього/неї/нього/них (після прийменника) | | | | | |
| `{poss(X)}` свій-присвійний «його/її/їхній» → «його/її/його/їхній» | | | | | |
| `{this(X)}` цей/ця/це/ці | | | | | |

Аргумент `X` — проста назва змінної без крапки (`{adj(ITEMNAME)}`, не `{adj(HERO.NAME)}`). Для персонажів — `{?X.GENDER}…{?}…{\?}`.

Модифікатори предметів (шаблон «Worn {ITEMNAME}») мають давати НАЗВУ з маркерами, щоб її теж можна було відмінювати: `Зношен{adj(ITEMNAME)}{.aj} {ITEMNAME}{.nn}`.

## 5. Числа

### 5.1. Слово після числа: `{.N1}…{.N2}…{.N5}…{.Nend}`

Процесор бере найближче попереднє число (або число всередині форм) і лишає потрібну форму: N1 — 1, 21, 31… (але не 11); N2 — 2–4, 22–24… (не 12–14) і дробові; N5 — решта (0, 5–20, 25…).

- `{DAYS} {.N1}день{.N2}дні{.N5}днів{.Nend}`
- `Залишилося {COUNT} {.N1}вільне місце{.N2}вільні місця{.N5}вільних місць{.Nend}`
- Англійське `{DAYS} {?DAYS > 1}days{?}day{\?}` замінюй саме так. Умови `{?X > 1}`/`{?X == 1}` для однини/множини в українському тексті прибирай, якщо їх повністю заміняє `{.N…}`. Але умова, яка змінює сенс (наприклад, `{?X == 0}`), лишається.

### 5.2. Назва-змінна після числа: `{.c}`

`{COUNT} {TROOP}{.c}` → «1 імперський рекрут», «3 імперські рекрути», «7 імперських рекрутів». Після дієслова, що вимагає знахідного (привезти, привести, купити, найняти), — `{.ca}`: «привезти 21 скриню», «привести 1 імперського рекрута». Для товарів з полем Plural: `{COUNT} {PLURAL(ITEM)}{.c}` → «1 мішок зерна», «5 мішків зерна». Англійське `{?COUNT > 1}{PLURAL(ITEM)}{?}{ITEM}{\?}` заміни на `{PLURAL(ITEM)}{.c}`.

## 6. Імена та назви (транслітерація)

- Вигадані імена Кальрадії передавай за вимовою, українським правописом. Однакова назва всюди однакова — дивись глосарій.
- Загальні правила: i → і; y (голосний) → и; ee → і; ae/ai перед приголосним → е/ай за вимовою; кінцеве -ai/-ay після голосного → -ай/-аї (Aserai → Асераї); ia → ія, io → іо, ie → іє; g → г; h → г (вландійські, баттанські, імперські, стургійські імена) але х у асерайських і хузаїтських (kh → х); ch → ч (стургійські, вландійські), х (імперські грецькоподібні, баттанські кельтські); j → дж; q → к; w → в; th → т; ph → ф; ts/tz → ц; x → кс; c перед e/i → с (імперські: Lucon → Лукон, але Caladog → Каладог); подвоєння приголосних зберігай (Battania → Баттанія).
- Ключові: Calradia — Кальрадія; Calradic Empire — Кальрадійська імперія; Northern/Western/Southern Empire — Північна/Західна/Південна імперія; Vlandia — Вландія (вландієць, вландійський); Sturgia — Стургія (стургієць, стургійський); Battania — Баттанія (баттанець, баттанський); Khuzait — хузаїт (хузаїти, хузаїтський), Khuzait Khanate — Хузаїтське ханство; Aserai — асерай (мн. асераї, асерайський), Aserai Sultanate — Асерайський султанат; Neretzes — Неретцес; Neretzes’ Folly — Безумство Неретцеса; Istiana — Істіана; Arzagos — Арзагос; Rhagaea — Рагея; Garios — Гаріос; Lucon — Лукон; Derthert — Дертерт; Caladog — Каладог; Raganvad — Раганвад; Monchug — Мончуг; Unqid — Ункід; Urkhun — Уркхун.
